# MyTicket – Movie Ticket Reservation System

A Java Swing-based Movie Ticket Reservation System developed as an academic group project.

## CORE WORKFLOW

MyTicket is a Java Swing-based Movie Ticket Reservation System developed as an academic group project. It is designed to provide users with a simple and convenient interface for browsing available movies, viewing movie details, selecting seats, and simulating ticket reservations.

The application focuses on developing an interactive and user-friendly graphical interface using Java Swing. Users can explore movies, choose their preferred cinema schedules, select seats, and view their booking confirmations through simulated transactions.

The system also incorporates ZXing for generating unique QR codes for individual movie tickets. Each generated QR code represents a specific ticket and contains its corresponding reservation information, such as the movie title, seat number, screening date, and time.

### Objectives
- Develop a user-friendly interface for a movie ticket reservation service.
- Allow users to browse movies and view their details.
- Provide an interactive seat selection and ticket reservation experience.
- Simulate the movie booking and confirmation process.
- Generate unique QR codes for individual movie tickets using ZXing.
- Display ticket information through generated QR codes.
- Demonstrate the basic workflow of an online movie ticket reservation platform.

### Planned Features

#### User Module

- **Movie Browsing** – Display a collection of available movies with posters, titles, genres, and descriptions.
- **Movie Details** – View movie information, duration, ratings, and available schedules.
- **Schedule Selection** – Choose a preferred movie date and screening time.
- **Seat Selection** – Display a visual seating arrangement where users can select available seats.
- **Ticket Reservation** – Simulate the reservation process and display booking details.
- **Booking Confirmation** – Generate a sample booking confirmation with a unique reservation number.
- **QR Code Generation** – Generate a unique QR code for every reserved ticket using ZXing.
- **Ticket Information** – Include movie title, cinema, seat number, screening date, time, and reservation number in the QR code.
- **QR Code Scanning** – Allow generated QR codes to be scanned using a phone or QR code reader to view the ticket information.
- **Reservation History** – Display previously simulated reservations during the application session.
- **User Profile Interface** – Display sample account information and provide a profile management interface.

#### Administrator Module

- **Movie Management** – Provide interface options to add, edit, and remove movies.
- **Schedule Management** – Provide options for managing movie schedules.
- **Reservation Management** – Display simulated customer reservations.
- **Dashboard** – Display sample statistics such as available movies, total reservations, and simulated ticket sales.
 
### Technologies Used

- **Java** – Main programming language.
- **Java Swing** – Graphical user interface development.
- **ZXing** – Integrated development environment.
- **Git and GitHub** – Version control and project collaboration.

### Project Structure

- **model** – Contains application data classes, including movies, users, schedules, seats, and reservations.
- **service** – Handles application logic, reservation processing, and QR code generation.
- **view** – Contains Java Swing forms and graphical user interfaces.
- **util** – Contains helper classes and utility functions.

### Project Limitations

- The application does not use an actual database or backend server.
- Movie reservations and transactions are simulated.
- User accounts and reservation information are not permanently stored.
- QR codes are generated for demonstration and ticket information purposes.
- QR code generation does not provide real payment processing or online ticket verification.
